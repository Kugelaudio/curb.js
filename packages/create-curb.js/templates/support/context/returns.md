# Returns and refunds

- Unused items can be returned within 30 days of delivery.
- Return shipping is free for damaged or wrong items, and paid by the customer otherwise.
- A refund goes back to the original payment method after the returned item arrives.
- Worn or washed items cannot be returned.
- An exchange is a return plus a new order.
