# `<Instruction>`

Behavioural guidance for the model. It takes no props.

```tsx
import { Instruction } from "curb";

function Instruction(props: { children: ReactNode }): ReactNode;
```

## Example

```tsx
<Instruction>Never promise that a claim will be paid.</Instruction>
```
