# `curb start`

Runs the LiveKit voice worker in production mode ([Self-hosting](../hosting.md)). With
`CURB_MANAGEMENT_ADDR` and `CURB_MANAGEMENT_TOKEN`, it also serves host protocol v1 for its calls.

```bash
npx curb start
```
